NonStop Copilot Architecture

A local assistant beside the operator's CAIL terminal session. It answers with citations to the HPE manuals and to named veterans, proposes commands that run only after approval, and warns early using veterans' own warning patterns. Every answer is scoped to the context the operator is actually in.
